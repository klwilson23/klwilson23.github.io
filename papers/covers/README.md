Journal cover images for the shelf at the top of the Papers page.

- Save each cover about 420 px tall as a JPEG under ~80 KB. They are displayed at
  150 px tall, so anything larger is wasted bandwidth.
- Add or remove an <img> line in papers/index.qmd to change which covers appear.
  Four or five looks best; more than that and they shrink on smaller screens.
- Prefer covers of issues that actually contain one of your papers, and link each
  one to that paper.
