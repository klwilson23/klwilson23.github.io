# files/

- Put your CV here as `wilson-cv.pdf`. The navbar "CV" link and klwilson.org/curriculum-vitae/ both point to this exact filename.
  To update your CV, upload a new file with the same name.
- Put copies of papers in `papers/`, named like `wilson-2024-coho.pdf`, and link them from `papers/papers.yml`:
  `pdf: ../files/papers/wilson-2024-coho.pdf`
- Check each journal's self-archiving policy first (e.g. via Sherpa Romeo). The accepted manuscript is usually allowed; the publisher's PDF often isn't.
